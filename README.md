## 🌌 Overview

Pragmata Memory Forge is a **single-player memory editor and gameplay modifier** engineered for enthusiasts who enjoy bending the rules of their own sandbox. Unlike grey-market tools that slap a patch onto a running process and call it a day, this project treats memory as a living material — something to be heated, shaped, cooled, and polished.

The forge is built around three pillars:

1. **Precision** — pinpoint value sculpting with multi-level pointer chains.
2. **Reversibility** — every modification leaves a breadcrumb trail for restoring the original snapshot.
3. **Delight** — an interface that feels like a workshop, not a spreadsheet.

Whether you want to stroll through a post-apocalyptic wasteland with infinite stamina, replay a favourite boss with a self-imposed challenge, or simply experiment with numbers for curiosity’s sake, the Forge gives you a dignified way to do it.

## ⚒️ The Forge Ethos

Most memory tools are loud. They flash banners, demand privileged integrations you never asked for, and treat your save files as disposable. Pragmata Memory Forge takes the opposite route — a **quiet, respectful companion** for the games you already love.

- **Local-first.** Everything happens on your machine. No telemetry, no cloud round-trips.
- **Snapshot before sculpt.** A reversible ledger captures pre-modification state.
- **No nagging.** No pop-ups, no upsell screens, no artificial limits on session length.
- **Craft, don’t smash.** You choose values deliberately; the forge never brute-forces on your behalf.

Think of it as the difference between a locksmith and a battering ram.

## 🌠 Feature Constellation

A long list, deliberately grouped so you can skim or dive deep.

### 🔍 Memory Discovery & Analysis
- Multi-pass value scanner with narrowing filters (exact, fuzzy, increased/decreased).
- Snapshot diffing across time to catch volatile addresses.
- Pointer path resolution with automatic base-pointer detection.
- Address table with colour-coded stability indicators.
- Freeze, lock, and pulse modes for individual entries.

### 🛠️ Value Sculpting Tools
- Numeric editor for integers, floats, doubles, and packed structures.
- Byte-editor view for hand-carving hex sequences.
- Multi-select bulk edit across rows.
- Undo stack with named checkpoints.
- Template system for sharing address layouts *within your own circle* — no cloud required.

### 📂 Profile & Session Management
- Named profiles per game title.
- Auto-load last session on relaunch.
- Export/import of profile bundles as human-readable files.
- Session history with timestamps and change summaries.

### 🎨 Interface & Experience
- Dark “obsidian” theme and light “parchment” theme.
- Keyboard-driven command palette.
- Draggable panels with persistent layout memory.
- Configurable hotkeys with conflict detection.
- Compact “overlay” mode for side-by-side play.

### 🔐 Safety & Integrity
- Read-only mode for exploratory sessions.
- Cooldown between writes to reduce detection by misbehaving engines.
- Built-in validator that flags suspicious values before committing.
- Crash-safe writes with automatic rollback on failure.

### 📈 Extensibility
- Scriptable hook system for custom post-processing.
- Plugin folder for community-authored mini-tools.
- Event stream you can subscribe to from your own utilities.

## 🖥️ Supported Environments

Pragmata Memory Forge is designed for **single-player, offline** experiences. The forge does not participate in any networked session, and it explicitly refuses to attach to processes flagged as multiplayer hosts.

| Platform | Status | Notes |
|----------|--------|-------|
| Windows 11 (2026 builds) | ✅ Primary | Full feature parity |
| Windows 10 | ✅ Stable | Minor theming caveats |
| Linux (Proton/Wine runtimes) | 🟡 Experimental | Read-focused workflows shine |
| macOS (Apple silicon) | 🟡 Experimental | Community-maintained branch |

Because the forge treats memory as craft, the most rewarding targets are titles with rich numeric systems — RPGs, city builders, survival sims, and sandbox games. Arcade racers and twitch shooters rarely offer the same sculptural satisfaction.

## 📱 Responsive Interface Blueprint

The interface adapts like a well-tailored garment. On a wide desktop monitor, panels sprawl comfortably with generous whitespace. Shrink the window and the layout reflows gracefully:

- **Wide (>1440px):** Three-column workshop with live preview.
- **Standard (1024–1440px):** Two-column with collapsible side rails.
- **Compact (768–1024px):** Single column with tabbed sections.
- **Narrow (<768px):** Touch-friendly target sizes and swipe gestures.

Even the smallest layout retains every function — nothing is sacrificed, only rearranged. A **responsive UI** in a desktop tool sounds like an oxymoron until you realise how often you play in windowed mode beside a wiki.

Pragmata Memory Forge is intended exclusively for:
